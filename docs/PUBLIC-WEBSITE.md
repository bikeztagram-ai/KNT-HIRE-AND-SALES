# KNT Public Website Foundation

## Public/private boundary

- `/` is the public KNT marketing and sales website.
- `/app` remains the private engineer workspace and is still protected by Supabase when configured.
- The existing engineer application is not being replaced by the public site.

## Brand direction

- Black / charcoal industrial base.
- KNT orange accent.
- White and metallic-grey typography.
- Forklift-led visual identity.
- Shared vector logo at `public/knt-logo.svg`.

## Current public stock

- Daewoo D15S.
- Mitsubishi Grendia 20.

Only the machine names and availability context are published in the first slice. Specifications, hours and prices remain pending KNT confirmation.

## Verified-content rule

Public directory information may be used as research evidence but must be confirmed before final launch. Do not invent email addresses, machine specifications, prices, opening hours or marketplace URLs.
